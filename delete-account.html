Suppression de compte - EcodePro

Cette page explique comment les utilisateurs de l'application EcodePro peuvent demander la suppression de leur compte et des données associées.

Comment demander la suppression de votre compte

Pour supprimer votre compte, veuillez envoyer une demande par email à :

support@ecodepro.app

Veuillez inclure les informations suivantes :

  • Votre nom
  • Votre numéro de téléphone utilisé dans l'application
  • Le nom de votre auto-école (si applicable)

Données supprimées

Lorsque votre demande est traitée, les données suivantes seront supprimées :

  • Informations personnelles (nom, téléphone)
  • Compte utilisateur
  • Données d'utilisation associées
  • Informations liées à votre auto-école

Délai de traitement

La suppression des données sera effectuée dans un délai maximum de 30 jours après réception de la demande.

Données pouvant être conservées

Certaines données peuvent être conservées temporairement si cela est nécessaire pour respecter des obligations légales ou prévenir les fraudes.
