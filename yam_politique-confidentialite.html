YAM
Politique de confidentialité

Dernière mise à jour : 25 juin 2025  ·  Application mobile YAM (Android / iOS)

1. Introduction

YAM est une application mobile de gestion commerciale destinée aux petits commerçants en Afrique. Cette politique de confidentialité décrit comment nous collectons, utilisons et protégeons vos données personnelles lorsque vous utilisez notre application.

En utilisant YAM, vous acceptez les pratiques décrites dans cette politique.

2. Données collectées

Nous collectons uniquement les données nécessaires au fonctionnement de l'application :

  • Informations de compte : nom, prénom, numéro de téléphone, adresse email (optionnelle)
  • Informations du commerce : nom du commerce, secteur d'activité, ville
  • Données commerciales : ventes, produits, clients, dépenses, stocks
  • Données techniques : tokens d'authentification JWT stockés localement

Nous ne collectons pas de données de localisation GPS, de contacts téléphoniques, ni de données biométriques.

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Créer et gérer votre compte utilisateur
  • Enregistrer et afficher vos transactions commerciales
  • Générer des reçus et rapports pour votre commerce
  • Assurer la sécurité de votre session (authentification)

Nous n'utilisons pas vos données à des fins publicitaires et ne les vendons pas à des tiers.

4. Stockage et sécurité

Vos données sont stockées sur des serveurs sécurisés. L'accès est protégé par un système d'authentification JWT (JSON Web Token) avec expiration automatique. Les communications entre l'application et nos serveurs sont chiffrées via HTTPS/SSL.

Le mot de passe est stocké sous forme hashée (bcrypt) — nous n'avons jamais accès à votre mot de passe en clair.

5. Partage des données

Nous ne partageons vos données avec aucun tiers, sauf dans les cas suivants :

  • Obligation légale ou demande d'autorité compétente
  • Avec votre consentement explicite

6. Vos droits

Conformément aux principes généraux de protection des données, vous avez le droit de :

  • Accéder à vos données personnelles
  • Corriger vos informations
  • Supprimer votre compte et toutes les données associées
  • Exporter vos données commerciales

Pour exercer ces droits, contactez-nous via les coordonnées en section 8.

7. Conservation des données

Vos données sont conservées tant que votre compte est actif. En cas de suppression de compte, toutes les données personnelles sont effacées dans un délai de 30 jours, sauf obligation légale contraire.

8. Contact

Pour toute question relative à cette politique de confidentialité ou pour exercer vos droits, contactez-nous à :

Email : contact@unlimitedlabs.bf

Responsable : UNLIMITED LABS, Ouagadougou, Burkina Faso

9. Modifications

Nous nous réservons le droit de modifier cette politique à tout moment. En cas de modification substantielle, vous serez notifié via l'application. La date de dernière mise à jour est indiquée en haut de cette page.
